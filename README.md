# 🚀 DevFolio Builder

**DevFolio Builder** is a SaaS-style web application that allows developers and students to generate their own professional portfolio website by simply filling out a form.

Instead of manually coding a portfolio, users can enter their details, skills, and projects — and instantly get a beautiful portfolio layout.

This project combines modern UI (designed using Stitch AI) with a Django-powered backend to create a real, usable product.

---

## ✨ Features

- User authentication (Login / Register)
- Dashboard for managing portfolio data
- Multi-section portfolio creation form
- Live portfolio preview
- Theme selection (Dark / Light / Minimal)
- Automatically generated portfolio layout
- Download portfolio as HTML
- Clean SaaS-style UI

---

## 🛠️ Tech Stack

- **Frontend UI:** HTML, CSS (generated with Stitch AI)
- **Backend:** Django
- **Database:** SQLite
- **Version Control:** Git & GitHub

---

## 🎯 Project Goal

The goal of this project is to build a real-world product that helps developers and students create their own portfolio websites easily, while demonstrating practical knowledge of:

- Django models, views, templates
- Form handling
- Dynamic content rendering
- UI to backend integration
